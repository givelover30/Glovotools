# CALCTOOLS Phase B5 — Final Taxonomy Architecture & References Hub Evaluation

## 1. Evaluation: Dedicated "References & Guides" Hub
- **Current State:** 202 static/searchable reference tables and guides (`category === 'guides'`) are currently scattered across 9 operational tool hubs (`Calculators`: 160, `Business & Management`: 21, `Trackers`: 7, etc.).
- **Proposal:** Introduce a 21st Tool Hub titled **"Guides & References"** dedicated exclusively to reference sheets, cheat sheets, periodic tables, and glossaries.
- **Pros:** Clean separation of active calculation/conversion tools from static educational reference content; improves user browsing experience.
- **Cons / Risks:** Requires updating hub registries and ensuring search indexing correctly maps reference pages.

## 2. Final Target Architecture
- **21 Operational Tool Hubs** (including Guides & References).
- **55 Subject Categories** (49 canonical + 6 promoted orphan categories).
- **492 Canonical Subcategories** (with dynamic fallback for orphan subids).
